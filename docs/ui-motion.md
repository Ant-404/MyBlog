# 前台阅读与动态效果

此 UI 阶段保留 React、原生 CSS 和现有 Spring Boot 接口，不需要修改数据库。后续已实现项目展示、文章专题、说说及后台管理；这些新增内容模块需要手动执行 V10，见 [内容模块说明](showcase.md)。

## 添加首页横幅

将图片放入 `frontend/public/images/`，使用 `home` 加数字命名，例如：

```text
home1.jpg
home2.jpg
home3.webp
home4.png
```

支持 JPG、JPEG、PNG、WebP、AVIF，不要求编号连续。Vite 在开发和构建时自动扫描，不需要改组件或维护列表。开发服务添加、删除图片后自动刷新；正式部署添加图片后，需要重新构建并发布前端（仅复制到已部署目录不会更新构建中的候选列表）。建议使用宽幅图片，压缩到合适尺寸；手机与桌面当前共用图片，默认取景为 `center 25%`，在 `styles/experience.css` 的 `.hero-picture` 调整。

- 首次进入随机选择一张；有多张时每 12 秒随机切换，排除当前图片。
- 下一张预加载成功后再淡入，加载失败的图片本次访问不再选择；没有可用图片时使用本地风景插图。
- 右下角“换张风景”可手动切换，“暂停横幅动画”暂停自动换图和波浪。仅一张图片时仍有流动波浪。
- 三层波浪分别以 24、20、16 秒循环，方向、透明度与位置错开。
- 页面进入后台、横幅被隐藏时不自动换图；系统减少动态效果或外观设置关闭动态效果时，停止自动切换和波浪动画。
- 动画样式位于 `frontend/src/styles/experience.css`，组件为 `HeroBanner.tsx`；图片发现插件位于 `frontend/vite.config.ts`。

## 阅读布局与搜索

文章页不再展示首页大横幅和公共双侧栏。宽屏使用正文与右侧吸顶目录，较窄屏幕改为正文内可展开目录。目录高亮当前章节并在内部滚动，支持直接打开带章节锚点的网址。现有 `article-heading-N` 锚点继续保留。

“专注阅读”隐藏桌面目录并居中正文，偏好保存在本浏览器。“分享文章”复制当前链接（包括当前章节锚点），剪贴板不可用时提示手动复制地址栏。外观设置增加动态效果开关和恢复默认按钮。

手机搜索收为图标，点击展开输入面板；`/`、Ctrl/Cmd+K 仍可打开。搜索增加标题与摘要关键词高亮、摘要预览、上下键选择、Enter 打开所选文章。未选择结果时 Enter 进入完整搜索页；Esc 关闭，手机焦点返回搜索按钮。全文检索继续使用后端公开文章 API。

卡片摘要调整至 14px、日期与标签为 12px，辅助文字加深。文章无封面或卡片封面加载失败时，显示分类和文章标题生成的 CSS 封面，保留后台已设置的所有封面。

## 现有功能增强

- 代码块：显示语言标识，超过 20 行默认折叠；支持展开、收起、自动换行、纯文本复制。编辑器预览与前台共用解析器及语言标识，交互控制位于前台文章组件。
- 图片预览：支持前后切换、方向键、手机左右滑动、原始尺寸/适应窗口、图片说明；关闭后回到最初点击的图片。原始尺寸大图可在预览区域滚动查看。
- 评论：显示字数，在停止输入 400ms 后将当前账号（或游客）和文章的正文草稿保存至本标签页 sessionStorage，刷新可恢复；成功提交清空正文后移除草稿。不同账号和文章草稿隔离；关闭标签页后不保证保留，不发送到后端。存储不可用时提示，仍可提交评论。
- 音乐：列表循环、单曲循环、随机播放；记忆上次曲目与播放模式，刷新后仍需主动点击播放；支持浏览器 Media Session 播放、暂停、切歌与定位（依赖设备支持）。沿用公开音源与失败提示。
- 追番：关键词、状态、排序保存在网址，支持刷新和浏览器前后导航，较长观后感可展开。没有新增年份字段或外部同步接口。

后台横幅管理、评论楼中楼、番剧外部导入、文章预渲染与分享元数据尚未实现。新增内容页面的独立实现说明见 [内容模块说明](showcase.md)。

## 验证入口

`npm run build` 检查类型和生产打包。`tests/experience.spec.ts` 覆盖换图、动画暂停、失败回退、手机键盘搜索、阅读布局与深链接、代码折叠、图片预览、评论草稿和追番筛选；横幅多图测试使用拦截的图片列表，不向用户图片目录添加测试图片。原有前台、编辑器、图片、评论与音乐测试继续用于回归。

2026-10-15 验证：格式检查及生产构建通过；使用 Edge 与独立 H2 后端分批完成 32 项相关浏览器测试。首轮评论测试因辅助提示的 status 角色重复失败，修正后已复测通过。另实际临时添加 `home99999.jpg`，确认自动发现、手动换图及删除后候选列表更新均通过，临时文件已删除。已检查桌面首页、手机首页、文章页及手机搜索截图；未修改用户的原始图片。
