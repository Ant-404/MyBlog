# 逐步完善憨Ant的小站

| 步骤 | 范围 | 状态 |
| --- | --- | --- |
| 1 | 个人信息替换、管理员登录/退出、权限保护与后台工作台 | 已完成 |
| 2 | 后台文章列表、新建、编辑、删除、草稿、发布与置顶 | 已完成 |
| 3 | Markdown 实时预览、编辑器工具栏、已有草稿自动保存 | 已完成 |
| 4 | 封面、正文图片上传与文件管理 | 已完成 |
| 5 | 分类、标签、友链和站点设置管理 | 已完成 |
| 6 | 文章目录、进度条、上一篇/下一篇、代码高亮 | 已完成 |
| 7 | 评论审核、RSS、站点地图与阅读统计 | 已完成 |

每一步交付可运行的页面、真实接口、对应数据库迁移和行为验证。前端继续每页一个 `.tsx` 文件；后台页面放在 `pages/admin/`；后端按业务模块扩展。

站点展示姓名统一为“憨Ant”。项目名称及数据库名仍是 MyBlog。保留 Mizuki 为设计来源致谢，不将原作者的账号、网站或个人资料作为本站作者信息。初始友链中的主题项目改为 TypeScript 官方文档。地理位置、联系方式和头像没有现成的个人资料，暂不编造。
