# 第一批互动小功能

## 导航与入口

顶栏统一为：首页、文章、项目、留言墙、追番、友链、关于。文章内提供分类、专题、归档和标签四种浏览方式；分类按主题筛选，专题按顺序阅读系列文章。说说的旧地址 `/moments` 跳转到 `/guestbook`，后台保留历史说说管理与数据。

随机漫游的按钮与接口已移除。页脚仅保留 Mizuki 和管理后台链接，首页随机横幅和流动波浪继续保留。

## 天气氛围

在“外观设置 → 横幅天气氛围”选择晴天、雨天、飘雪、微光。偏好只保存在当前浏览器，不读取地理位置，也不请求真实天气接口。

效果限制在横幅内，不拦截点击；采用少量 CSS 粒子。横幅暂停或页面在后台时暂停；系统要求减少动态效果或关闭站点动态效果时隐藏。恢复默认外观会回到晴天。

组件为 `WeatherAtmosphere.tsx`，样式位于 `styles/members.css`，偏好键为 `myblog-weather`。原有首页多图自动发现和流动波浪继续保留。

## 互动留言墙

`/guestbook` 使用验证过邮箱的账号发布，支持四种便签颜色，最多 500 字，不支持 HTML。初始为空状态，不伪造访客留言。用户在个人中心查看自己的待审核、已公开与被拒绝便签，也可删除。

后台“用户与社区 → 留言墙审核”提供审核和删除。入口放在顶栏、手机导航和个人中心；数据持久化需要 V11。完整配置和保障措施见 [会员说明](members.md)。
