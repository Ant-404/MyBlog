## 范围与结论

检查 React 路由、全部后台页面、共用表单、Spring Boot 接口、数据来源和回归测试，并在独立 H2 环境逐页访问。未更改用户 MySQL、删除历史数据或重启用户正在使用的服务。

现用模块都有实际用途，没有依据仅凭菜单数量删除其中某项。问题主要在导航平铺、工作台概况不完整、图片库访问旧文件的能力不足，以及旧需求遗留文案和测试。

## 已修复

- 菜单分为“内容与素材”“互动与链接”“生活与站点”，保留现有地址和专题二级入口。
- 工作台使用真实管理数据，区分草稿、已到发布日期和等待发布日期的文章；分类与标签覆盖后台实际记录。
- 相册前台使用叠放相框、日期与说明；后续按页面协调要求，统一为本站横幅、侧栏、圆角内容卡片和标题样式，保留照片叠放与搜索。
- 搜索匹配相册名、介绍、照片说明，隐藏相册不会进入结果；百分号、下划线等按普通字符匹配。
- 未指定封面时使用首张照片；空册显示占位；列表仅加载最多三张预览地址，不加载全部照片内容。
- 图片库新增每页 50 张和文件名搜索，上传后返回第一页并清除筛选，确保新文件可见。
- 评论和便签越界页、删除末页最后一条后返回有效页。
- 阅读统计的“待管理评论”改为“文章评论总数”，对应当前即时发布规则。
- README 移除不存在的会员页面文件引用和重复留言墙条目。
- 修复旧测试对已删除会员 helper、审核按钮和后台原页跳转的依赖，更新新增相册后的导航预期。

## 仍建议补充，当前没有实现

| 优先级 | 能力 | 原因和范围 |
| --- | --- | --- |
| 高 | 管理员修改密码 | 需要验证旧密码、保存新密码、使旧会话失效的完整流程；目前只有初始化与登录 |
| 高 | 备份/恢复说明或工具 | 应一起覆盖 MySQL、上传图片、歌曲和 library.json；后台没有一键全站备份/恢复，单独导出文章不足以恢复网站 |
| 中 | 音乐移除与排序 | 上传后的日常维护不完整；建议先支持从列表移除或隐藏，文件删除需区分后台上传与源目录文件 |
| 中 | 照片批量上传/选择 | 当前逐张操作可用，大相册效率较低；可补多选、进度与失败重试 |
| 低 | 评论/便签搜索、相册列表筛选 | 内容量增长后增加，目前已有分页或全列表可用 |
| 可选 | 自定义拍摄日期 | 历史旅行相册应单独设置拍摄日期，避免把创建日期当拍摄日期 |

## 多余或应继续收拢的部分

- 会员、通知、举报和访客登录注册已取消，不应重新加入后台；旧表有历史关联，未删库表。
- 旧说说页面已撤下，前后台旧地址继续跳转留言墙；旧内容与接口保留兼容，不新增一级菜单。
- 后端仍有旧 QQ 歌单配置/导入接口，当前前端使用本地音乐。这部分可在确认外部客户端依赖后清理，不能把旧 music_tracks 数量当成本地歌曲数。
- 相册组织展示，图片库负责复用和清理，两者不能合并为直接删除文件的入口。
- 不建议为个人博客增加复杂多角色系统、运营看板、审核工单或独立通知中心。

后端在独立 H2 环境验证权限、搜索、分页、版本和计数，不能替代真实 MySQL 升级实测。Edge 浏览器连接真实测试 API，覆盖全部后台页面加载和核心增删改。已目视检查画廊浅色、深色、手机及工作台截图。

本次后端完整 53 项测试通过；前端生产构建、TypeScript、Prettier、Java 格式和 Git 空白检查通过。浏览器共 64 项用例分批通过：全量运行先有 63 项通过，导航预期漏写“相册”的一项更新后复测通过；新增画廊对文章搜索隔离的断言修正定位方式后，画廊与后台巡检 3 项最终复测通过。没有跳过失效测试或恢复旧会员/审核功能来通过检查。

相册仍需唯一 SQL 文件中的 V14。已经执行 V14 的库，本次画廊和后台整理没有增加迁移，只需更新代码并重启服务。当前页面没有管理员改密、音乐删除或一键备份按钮；上述建议不能当作已完成能力。
