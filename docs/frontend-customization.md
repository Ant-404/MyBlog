# 前台外观与交互

本轮参考 [Mizuki](https://github.com/matsuzaka-yuki/Mizuki) 的横幅波浪、卡片层次、主题色选择、文章日历及阅读辅助，在现有 React + TypeScript 上独立实现。没有迁移到 Astro，也没有引入原作者的个人资料或插图。保留用户已添加的 `home1.jpg` 和 `personal.jpg`。

## 图片与样式修改

| 修改内容 | 文件 | 说明 |
| --- | --- | --- |
| 首页横幅图片、取景位置 | `frontend/public/images/home数字.扩展名`、`frontend/src/styles/experience.css` 的 `.hero-picture` | 自动扫描 `home1.jpg`、`home2.webp` 等并随机淡入切换；默认 `center 25%`，生产环境增删图片后需重新构建 |
| 个人卡片背景图 | 同文件的 `.profile-scenery` | 当前为 `/images/personal.jpg` |
| 公共图片文件 | `frontend/public/images/` | 引用地址省略 `public`，例如 `/images/banner.jpg` |
| 颜色、间距与正文字号变量 | `frontend/src/styles/tokens.css` | 默认藤紫，也提供晴蓝、松绿、蔷薇、麦金 |
| 新增前台视觉样式 | `frontend/src/styles/blog-theme.css` | 悬浮导航、波浪、文章卡片、搜索、设置、日历、图片预览及响应式布局；在基础样式之后加载 |
| 横幅文字与页脚 | `frontend/src/layouts/BlogLayout.tsx` | 标题、副标题等站点资料仍由后台设置提供 |
| 文章封面与正文图片 | 后台文章编辑页 | 上传或从图片库选择后保存文章 |
| 个人头像 | 后台站点设置 | 选择图片后保存 |

`blog-theme.css` 主要样式限定在 `.blog-layout` 下，后台继续使用自身布局。主题变量由前后台共用。修改基础样式若没有反映到页面，应检查此文件的后置样式及对应媒体查询。

后续阅读布局、手机搜索、随机横幅和三层流动波浪使用最后加载的 `styles/experience.css`。新增交互、图片命名及部署注意事项见 [前台阅读与动态效果](ui-motion.md)，以下为初版交互记录。

## 已添加的交互

- 导航菜单以整条顶栏为基准居中，站点名与搜索/外观工具分列两侧，导航文字和图标统一对齐。手机展开为三列菜单，每项居中；平板适当缩短搜索框以避免挤压。相关规则位于 `blog-theme.css` 的 `.header-inner`、`.main-nav`、`.header-actions` 及对应媒体查询。
- 顶栏「外观设置」：浅色、深色、跟随系统，0–360° 连续主题色相滑条及五种预设颜色，三档正文字号，显示或隐藏横幅。设置保存在当前浏览器，不写入 MySQL，不改变其他访客的选择。禁用本地存储时本次访问仍可切换，但刷新后不保留。
- 首页网格和列表视图：记住当前浏览器的选择。
- 搜索联想：输入停止 250ms 后查询公开文章，显示最多四条结果；Enter 进入完整搜索页，Tab 可访问结果链接。`/` 或 `Ctrl/Cmd + K` 聚焦搜索，Esc 关闭。请求失败显示提示，旧请求结果不会覆盖新关键词。
- 文章日历：从公开归档读取实际发布日期，圆点代表当天有文章，点击查看文章链接。支持前后月份和点击月份回到本月。沿用响应式侧栏规则，窗口宽度不大于 1200px 时隐藏右侧栏。
- 回到顶部：下滑超过 320px 后显示，附页面滚动百分比。系统设置减少动态效果时直接返回顶部。
- 正文图片预览：点击无链接的正文图片，或键盘聚焦后按 Enter/空格，打开原图预览；Esc、关闭按钮或背景关闭，焦点回到原图。已经带链接的图片保留原来的链接行为。
- 代码复制：正文代码块右上角可复制纯文本，不包含高亮标记。剪贴板权限不足时提示手动复制；生产环境应使用 HTTPS。
- 加载骨架、卡片入场与悬停反馈：支持系统「减少动态效果」偏好。

页面仍然保持 `pages/XxxPage.tsx` 一页一个文件。新增组件按职责放在 `components/layout` 和 `components/blog`，浏览器偏好封装在 `hooks/useStoredPreference.ts`。背景白色点状纹理由原先的 CSS 点阵产生，现已移除，深浅模式均使用主题背景色。音乐、追番和调色样式位于 `styles/leisure.css`；新增接口及唯一 SQL 中的音乐/追番数据表说明见 [音乐与追番指南](leisure.md)。
