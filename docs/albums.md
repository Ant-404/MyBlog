# 相册

## 启用

1. 停止后端，备份 MySQL 数据库。
2. 手动执行 `database/MyBlog.sql` 完整文件，V14 会创建 `albums`、`album_photos`；可重复执行，不插入示例相册。已完成 V13 的库也可以单独执行文件末尾完整的 V14 更新块。
3. 重启后端，启动更新后的前端。

项目继续使用手动 SQL，不在启动时自动修改 MySQL。

## 使用

进入 `/admin/albums`（管理员登录），填写相册名称、介绍，点击“创建相册”。允许先建空相册，默认隐藏。

点击“上传 / 添加照片”，在图片库上传图片，再点对应图片的“选择图片”。可连续添加不同的图片，重复选择已在本册中的图片不会再次添加。每册最多 200 张；上传限制与现有图片库相同，每个文件最多 5MB，图片转换也复用现有逻辑。

每张照片可填写最多 500 字说明，用上下箭头调整顺序，点击“设为封面”设置本册封面。也可以独立上传或选择封面；封面为空时前台使用首张照片，没有照片时显示相机占位图。勾选“公开显示”，点击“保存相册”后生效。未保存的修改在离开、刷新或切换编辑对象时会提醒。

相册列表和详情沿用小站的横幅、侧栏及圆角内容卡片，标题、搜索框、配色和间距与项目等页面一致。列表采用双列叠放照片，手机单列，相框在悬停时轻微展开。日期为相册创建日期，当前没有自定义拍摄日期字段。明暗模式和减少动态效果跟随现有外观设置。

标题下方可按相册名称、介绍和照片说明搜索，300ms 后发送请求。地址中的 `q` 保存画廊查询，避免串入顶部文章搜索。空搜索、无匹配、加载和失败均有对应反馈。

前台 `/albums` 按相册排序值升序、ID 降序展示公开相册；点击进入 `/albums/:id`，照片按后台排列顺序显示。点击照片打开预览，支持按钮和左右方向键切换、Esc 关闭，关闭后焦点返回原照片。适配手机和明暗主题。

隐藏相册不出现在公开列表，直接访问其详情也返回 404。图片库原始图片地址仍沿用公开图片接口，隐藏状态不提供文件访问控制。

删除相册前需要确认；删除相册及照片关联不会删除图片文件。保存后被相册封面或照片引用的站内图片不能在图片库删除，需先解除引用并保存相册。未保存的照片选择尚未建立数据库引用。

## 接口

基础路径 `/api/v1`，响应使用项目统一 `ApiResponse`。所有 `/admin/` 接口需要 ADMIN 会话，写操作还需 CSRF token。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/albums?keyword=词` | 搜索公开相册名称、介绍和照片说明；photos 返回空列表，photoCount 为实际照片数 |
| GET | `/albums/{id}` | 公开相册详情及有序 photos；隐藏或不存在返回 404 |
| GET | `/admin/albums` | 包括隐藏相册的摘要列表 |
| GET | `/admin/albums/{id}` | 管理员详情，包括全部照片 |
| POST | `/admin/albums` | 创建相册，返回保存后的完整详情 |
| PUT | `/admin/albums/{id}` | 更新相册及全部照片，返回最新详情 |
| DELETE | `/admin/albums/{id}?version=N` | 按版本删除，级联删除照片关联 |

POST/PUT 的 JSON：

列表与详情额外返回 `createdAt` 和最多三个不同图片地址的 `previewImages`，用于日期和叠放相框；写入仍使用下面的原有输入字段。

```json
{
  "title": "周末散步",
  "description": "记录路上的小风景。",
  "cover": "/api/v1/media/example.png",
  "sortOrder": 0,
  "visible": false,
  "version": 0,
  "photos": [
    { "url": "/api/v1/media/example.png", "caption": "午后的风" }
  ]
}
```

名称必填且最多 200 字，介绍最多 2000 字，地址最多 1000 字；图片地址允许站内路径或 HTTP(S)，拒绝 javascript 等协议。照片列表最多 200 项，地址不能为空。排序范围 -10000 到 10000。更新与删除必须提交当前 version，冲突返回 409，并保留编辑输入。相册和全部照片在同一个事务中保存，失败时整体回滚。

## 验证

- `cd backend; mvn test`：包含相册生命周期、隐藏访问、照片顺序、版本冲突、图片引用保护、输入和权限校验。
- `cd frontend; npm run build`：TypeScript 检查与生产构建。
- `cd frontend; npx playwright test tests/albums.spec.ts`：独立 H2 测试环境中验证创建、真实上传、选择照片、说明、重排、封面、公开、放大预览、手机布局、隐藏、删除及图片清理。Windows 可设置 `PLAYWRIGHT_CHANNEL=msedge` 使用已安装 Edge。
